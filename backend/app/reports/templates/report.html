6. Methodology

Findings are produced by deterministic detection rules ({{ (scan.controls or [])|length }} controls mapped to the OWASP Top 10 CI/CD Security Risks) over safely-parsed workflow YAML, repository files and, where connected, read-only GitHub API settings, complemented by external scanners. Repository code is never executed. Evidence types: configuration (directly observed), inferred (indicator-based, needs confirmation), tool (external scanner output). Statuses: PASS, FAIL, NOT ASSESSED (data unavailable), NOT APPLICABLE, NEEDS MANUAL VALIDATION. AI agents annotate and prioritise but cannot create findings or change statuses.
